Conscious Creations · Premier Receiver Automation

From a messy delivery email to a verified PO receipt

This is the flow we're building a dashboard for. Most emails reconcile on their own; the ones that can't — low confidence, or missing a spec, quantity, POD or PO — surface to a person who approves or cancels them. That review is the heart of the tool.

The core flow
01 Emails arrive synthetic for now

Delivery-status mails land from vendors, warehouses, carriers and properties — any format, no fixed template, often several per order and several statuses for the same one.

02 Parse & extract built · stages 1–3

Read every body and attachment (HTML, PDF, scans via OCR, Excel). Detect the status keyword, then pull only the fields that matter for reconciling against the purchase order.

03 Reconcile against the PO mock · stages 4–5

Match each record to a Purchase Order line by PO + spec + description, then score how sure we are. The spec resolves the exact line; a fuzzy description match adds a second signal.

confidence: highmediumlownone

✓ Confident & complete

→ All three signals match, nothing missing
→ Auto-approved, no human needed
→ Staged PO receipt created

⚠ Low confidence or missing info

→ No clear PO match, or missing spec / qty / POD
→ Flagged → Exception Queue
↓ Goes to a person ⟶ this is what the dashboard is for
04
